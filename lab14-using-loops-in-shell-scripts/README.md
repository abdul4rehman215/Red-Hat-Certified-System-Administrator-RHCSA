# 🔁 Lab 14: Using Loops in Shell Scripts

---

## 📌 Lab Overview

This lab explores loop constructs in Bash shell scripting.  
Loops allow repetitive execution of commands and are essential for automating tasks such as file processing, counting operations, filtering results, and controlling execution flow.

The lab demonstrates practical usage of `for`, `while`, and `until` loops, as well as loop control statements like `break` and `continue`.

---

## 🎯 Objectives

By completing this lab, I was able to:

- Implement `for` loops to process lists and files
- Use `while` loops for condition-based repetition
- Apply `until` loops for reverse conditional logic
- Combine loops with conditional statements
- Control loop execution using `break`
- Understand practical loop-based automation patterns
