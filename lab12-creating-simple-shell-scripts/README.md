# 🖥️ Lab 12: Creating Simple Shell Scripts

## 📌 Lab Overview

This lab introduces foundational shell scripting concepts using Bash in a Linux environment.  
The focus is on writing simple scripts, making them executable, using variables, implementing control flow, and debugging script behavior.

This lab builds practical scripting skills required for Linux administration, DevOps automation, and security operations workflows.

---

## 🎯 Objectives

By completing this lab, I was able to:

- Write and execute basic Bash shell scripts
- Understand the purpose of the shebang (`#!/bin/bash`)
- Use variables inside scripts
- Implement conditional logic using `if` statements
- Use loops (`for`) for repetitive tasks
- Debug scripts using Bash trace mode (`-x`)
- Resolve execution permission issues

---

## 📋 Prerequisites

- Linux-based system with Bash installed
- Basic command-line familiarity
- Understanding of file permissions (`chmod`)
- Access to a text editor (nano used in this lab)

## 🧠 What I Learned

- Shell scripts are plain text files interpreted by Bash
- Execution permission is mandatory to run scripts directly
- Variables simplify automation workflows
- Control flow enables decision-based automation
- Debugging tools like `bash -x` help trace execution issues
- Even small scripts can automate repetitive operational tasks
