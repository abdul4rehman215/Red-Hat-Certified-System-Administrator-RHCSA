------------------------------------------------------------
Task 2 – Moving, Copying, Deleting Files
------------------------------------------------------------

toor@ip-172-31-10-205:~$ touch sample.txt

toor@ip-172-31-10-205:~$ mv sample.txt lab_files/

toor@ip-172-31-10-205:~$ ls lab_files/
sample.txt
✔ File successfully moved.

toor@ip-172-31-10-205:~$ cp lab_files/sample.txt lab_files/sample_copy.txt

toor@ip-172-31-10-205:~$ ls lab_files/
sample.txt  sample_copy.txt
✔ Both files present.

toor@ip-172-31-10-205:~$ rm lab_files/sample_copy.txt

toor@ip-172-31-10-205:~$ ls lab_files/
sample.txt
✔ Only sample.txt remains.

------------------------------------------------------------
Task 4 – Wildcard Operations
------------------------------------------------------------

toor@ip-172-31-10-205:~$ touch lab_files/file{1..5}.txt

toor@ip-172-31-10-205:~$ ls lab_files/
file1.txt  file2.txt  file3.txt  file4.txt  file5.txt  sample.txt

toor@ip-172-31-10-205:~$ rm lab_files/*.txt

toor@ip-172-31-10-205:~$ ls lab_files/
(No output — directory empty)
✔ lab_files is now empty.
