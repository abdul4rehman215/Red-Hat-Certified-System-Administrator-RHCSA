Task 2 – File Isolation & Permissions
------------------------------------------------------------

------------------------------------------------------------
Task 3 – Multiuser Targets
------------------------------------------------------------

-bash-4.2$ systemctl get-default
graphical.target

-bash-4.2$ sudo systemctl isolate multi-user.target
(System switched to text mode)

-bash-4.2$ sudo systemctl isolate graphical.target
(System switched back to graphical mode)

-bash-4.2$ sudo systemctl set-default multi-user.target
Removed symlink /etc/systemd/system/default.target.
Created symlink from /etc/systemd/system/default.target to /usr/lib/systemd/system/multi-user.target.
